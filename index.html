Tentang Ravelo Logistic

Ravelo Logistic adalah prototipe Sistem Informasi Ekspedisi.

  • Dashboard ringkasan data dan aktivitas paket
  • Input, edit, hapus, dan pencarian paket
  • Pelacakan nomor resi tanpa login pelanggan
  • Tanggal dan jam pengiriman serta tanggal perkiraan tiba
  • Pemantauan tahapan distribusi dan ekspor CSV
Catatan keamanan: login admin yang tertanam dalam JavaScript hanya simulasi dan tidak melindungi operasi database. Sebelum digunakan dengan data nyata, amankan operasi admin memakai Supabase Auth dan kebijakan RLS.
