Tentang Ravelo Logistic

Ravelo Logistic adalah prototipe Sistem Informasi Ekspedisi untuk kebutuhan tugas kuliah dan demonstrasi presentasi.

  • Dashboard ringkasan data dan aktivitas paket
  • Input, edit, hapus, dan pencarian paket
  • Pelacakan menggunakan nomor resi
  • Pemantauan tahapan distribusi
  • Ekspor laporan ke CSV
Penting: autentikasi dan penyimpanan pada versi ini hanya simulasi di browser. Jangan gunakan data pribadi sungguhan. Agar dapat dipakai banyak pengguna secara online, sistem perlu backend/database dan autentikasi server.
